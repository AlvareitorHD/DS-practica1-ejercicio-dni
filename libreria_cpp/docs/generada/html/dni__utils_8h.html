Detailed Description

API pública de una biblioteca C++ para DNI españoles.

Se permiten DNI con ocho dígitos ASCII y letra mayúscula o minúscula. No se contemplan NIE, CIF, espacios ni separadores.

◆ calcular_letra()

char calcular_letra ( int numero)

Calcula la letra de un número de DNI español.

Parameters
numeroNúmero entre 0 y 99999999, ambos incluidos.
Returns
Letra mayúscula correspondiente al módulo 23, o '\0' si el número es negativo o mayor que 99999999.
Note
Si se requiere mostrar el DNI completo, añadir ceros a la izquierda hasta formar exactamente ocho dígitos.

◆ validar_dni()

bool validar_dni ( const char * dni)

Comprueba que el DNI cumple el formato y que su letra es correcta.

Parameters
dniCadena C terminada en '\0', con ocho dígitos y una letra. Puede ser nullptr, en cuyo caso devuelve false.
Returns
true si es un DNI válido, false si está mal formado o su letra no se corresponde con el número.
Note
Se aceptan letras mayúsculas y minúsculas; no se eliminan espacios.
